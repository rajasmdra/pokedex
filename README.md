# Pokedex App

This is a dynamic and interactive Pokedex application built using **React and Tailwind CSS** that utilizes the **Pokedex Mimo API** to fetch and display real-time data about the Pokemon world. The app provides a clean, modern interface for enthusiasts to browse through the vast collection of Pokemon, search for specific entries, and view detailed statistics and information for each creature.

## Features

* **Pokemon Gallery** – Displays a grid of Pokemon fetched dynamically from the PokeAPI.
* **Search Functionality** – Find your favorite Pokemon instantly by searching for their names.
* **Detailed Statistics** – View comprehensive details for each Pokemon, including their types, abilities, base stats, and high-quality imagery.
* **Responsive Design** – Fully optimized for all screen sizes, from mobile devices to large desktops, thanks to Tailwind's utility-first styling.
* **API Integration** – Implements asynchronous data fetching to ensure a smooth and up-to-date user experience.
